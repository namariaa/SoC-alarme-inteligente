# Diagrama de Atividades

> Um diagrama de atividades mostra o comportamento dinâmico do sistema utilizando um modelo combinado de fluxo de controle e fluxo de objetos (dados).

<img width="848" height="826" alt="Activity Diagram1" src="https://github.com/user-attachments/assets/26433fb5-0260-4f04-a1be-a8045df1a4b0" />

Para o alarme inteligente, o Diagrama de Atividades foi utilizado para representar o fluxo de funcionamento do sistema durante o monitoramento do ambiente. O diagrama descreve as principais etapas do processo, desde a leitura dos sensores de temperatura e fumaça até a validação das leituras, comparação com os limites configurados, atualização do modo de operação e acionamento das saídas de alarme. Também são representadas as decisões relacionadas à validade das leituras e à ocorrência de uma situação de alerta ou emergência, permitindo visualizar o comportamento esperado do sistema.
